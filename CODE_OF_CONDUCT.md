# Code of Conduct

glyphfix exists so that communities around the world can rescue their own
written heritage. That only works when everyone feels welcome to contribute,
regardless of experience, language, background or identity.

## Our standards

Everyone participating in this project (issues, pull requests, discussions,
reviews) is expected to:

- Be respectful and patient. Many contributors are not professional
  programmers and many are not native English speakers.
- Give constructive feedback: comment on the work, never on the person.
- Assume good intent, and ask questions before assigning blame.
- Respect that maintainers and reviewers volunteer their time.

The following are not tolerated:

- Harassment, insults, or discriminatory language of any kind.
- Personal attacks, trolling, or deliberate intimidation.
- Publishing other people's private information without permission.
- Sustained disruption of discussions or reviews.

## Scope

This code of conduct applies to all project spaces: the repository, issues,
pull requests, discussions and any official communication channel, as well as
situations where someone represents the project in public.

## Enforcement

Report violations privately to the maintainers by email or through a GitHub
report. Reports are handled confidentially. Maintainers may edit or remove
comments, reject contributions, or temporarily or permanently ban anyone whose
behavior violates this code of conduct.
